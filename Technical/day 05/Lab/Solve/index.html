Differences between GET and POST methods:

  • GET: Appends form-data into the URL in name/value pairs. Length of a URL is limited. Never use GET to send sensitive data (like passwords). Useful for form submissions where a user wants to bookmark the result.
  • POST: Appends form-data inside the body of the HTTP request (data is not shown in URL). Has no size limitations. More secure than GET because user-input is not visible in URL.
