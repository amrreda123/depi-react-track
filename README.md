## 🎯 About The Repository

This repository tracks my full learning journey in the **Digital Egypt Pioneers Initiative (DEPI)** — a national scholarship program by the Egyptian government to build world-class tech talent.

It contains all **demos**, **lab exercises**, and **assignments** from each training session, covering everything from HTML fundamentals to React.js.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```sh
   git clone https://github.com/amrreda123/depi-react-track.git
   ```
2. **Navigate into any day's folder:**
   ```sh
   cd depi-react-track/day1/Demo
   ```
3. **Open any `.html` file** directly in your browser — no build step needed.
